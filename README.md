⏰ Neon Clock Pro 2.0

A stylish and interactive Neon Digital Clock built using HTML, CSS, and JavaScript. This project displays the current time and date with a modern neon-inspired user interface.

🚀 Live Demo

https://jeyabharathy30092006-cpu.github.io/Neon-Clock/

✨ Features
- 🕐 Real-time digital clock
- 📅 Current date display
- 💡 Neon-style user interface
- 🔔 Alarm functionality
- 🎨 Smooth animations and visual effects
- 📱 Responsive design
- ⚡ Lightweight and fast

🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling, neon effects and animations
- JavaScript – Real-time clock, date and alarm functionality

📂 Project Structure

Neon-Clock
  * index.html
  * style.css
  * script.js
  * alarm.mp3.mpeg
  * README.md

⚙️ How to Run

1. Clone the Repository
git clone https://github.com/jeyabharathy30092006-cpu/Neon-Clock.git
2. Open the Project
Open the project folder in Visual Studio Code.
3. Run the Website
Open "index.html" in your web browser.

🎯 Project Objective

The main objective of this project is to create an attractive real-time digital clock while practicing frontend development concepts such as:
- JavaScript Date and Time
- DOM manipulation
- CSS animations
- Responsive web design
- Interactive UI development
- Audio integration
